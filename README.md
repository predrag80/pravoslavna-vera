# Православље

Веб апликација о православној вери: календар са празницима и постовима, Свето писмо, Псалтир,
Охридски пролог, Свети оци, учење корак по корак (Лествица) и интерактивна мапа храмова и манастира у Србији.

## Покретање

```bash
npm install
npm run dev        # развој: http://localhost:3000
npm run build      # статички сајт у out/ + индекс претраге (Pagefind)
npm run start      # преглед изграђеног сајта
npm test           # тестови календара, поста, пресловљавања, псалама и читања
npm run lint && npm run typecheck
```

Потребан је Node.js 20.9 или новији.

## Објављивање

Сваки push на `main` покреће `.github/workflows/objavljivanje.yml`: провера (lint, typecheck, тестови), израда и
постављање фасцикле `out/` на хостинг (https://pravoslavna-vera.prowebsystems.rs). Приступни подаци се уписују у
GitHub → Settings → Secrets and variables → Actions:

- FTP (cPanel): `FTP_SERVER`, `FTP_USERNAME`, `FTP_PASSWORD`, `FTP_DIR` (фасцикла поддомена на серверу, са `/` на крају);
- или SSH: `SSH_HOST`, `SSH_USER`, `SSH_KEY`, `SSH_DIR`, опционо `SSH_PORT`.
- Заштита лозинком док је апликација у припреми: `HTTP_AUTH_USER` и `HTTP_AUTH_PASS`. Када се тајне обришу, следеће објављивање уклања заштиту.

`public/.htaccess` подешава Apache (HTTPS, страна 404, кеширање). Сајт је статички: није потребан Node на серверу.

## Стек

| Део | Избор | Зашто |
|---|---|---|
| Оквир | Next.js 16 (App Router) + React 19 + TypeScript | Статички извоз (`output: 'export'`); када затреба API или база, уклони се та линија и додају се API руте. |
| Садржај | JSON (`src/data/`) и Markdown (`content/`) | Без базе и без спољног API-ја; измене иду кроз Git и могу да се прегледају. |
| Календар | `src/lib/kalendar.ts` | Пасхалија, стари календар, покретни празници и постови рачунају се локално. |
| Мапа | MapLibre GL + OpenFreeMap | Отворени код, без API кључа; груписање блиских светиња је уграђено. |
| Претрага | Pagefind | Статичка претрага целог сајта, ради и са ћирилицом. |
| Писмо | ћирилица у изворном тексту, латиница пресловљавањем | `src/lib/preslovljavanje.ts`, `src/lib/pismo-klijent.ts` |
| Без интернета | `public/sw.js` | Странице се чувају на уређају. |
| Фонтови | Cormorant Garamond, PT Serif, Manrope (`@fontsource`) | Уграђени у пројекат, са ћириличним словима. |

```

```

## Текст Светог писма

Текст није у репозиторијуму. Подаци се узимају искључиво из православних извора: текст ће бити додат из
издања које користи Српска православна црква (нпр. Синодски превод Новог завета), уз дозволу издавача.
Формат је `src/data/biblija/<књига>.json`, облика `{ "1": ["стих 1", "стих 2", …], "2": […] }` (id књиге из `src/data/knjige.json`);
чим фајл постоји, глава, читања дана и обележавање стихова га приказују без других измена.

## Читања дана и обележени стихови

- `src/data/citanja/2026.json`: Апостол и Јеванђеље на Литургији по датуму. Недеље су преузете са crkvenikalendar.rs,
  а велики празници су уобичајена читања по Типику; читања за радне дане још нису унета.
  Запис референце: `Мк 8:34-9:1; Лк 5:1-11` (рашчлањује `src/lib/citanja.ts`, тестови у `tests/citanja.test.ts`).
- Стране `/citanja/` и `/citanja/<датум>/` приказују текст из увезене Библије; картица са следећим читањима је и на екрану Данас.
- У свакој глави и у читањима стих се додиром бира, обележава једном од три боје или копира са референцом.
  Обележени стихови су на `/pismo/obelezeno/` и чувају се на уређају.

## Календар и слике празника

- Календар има приказ по месецима и Годишњи круг; додир на датум отвара „лист дана“ (превлачење лево/десно мења дан).
- Текстови значајних празника су у `content/praznici/<id>.md` (id из `src/data/praznici.json`); сваки има и своју страну `/praznik/<id>/`.
- Слике се преузимају са Wikimedia Commons:

```bash
npm run slike                          # преузима слике које још недостају
npm run slike -- --ponovo vaskrs       # поново бира слику за наведене празнике
```

Скрипта прихвата само слободне лиценце (јавно добро, CC0, CC BY, CC BY-SA), чува слике у `public/slike/praznici/`
и уписује аутора и лиценцу у `src/data/slike.json`; те податке апликација приказује испод сваке слике, што лиценце захтевају.
Шта се тражи за који празник уређује се у `scripts/slike-izbor.json` (тачан назив фајла као први кандидат има предност).

## Мапа

Подразумевана подлога је OpenFreeMap (бесплатна, без кључа). Друга подлога се поставља у `.env.local`:

```
NEXT_PUBLIC_MAP_STYLE=https://…/style.json
```

За рад без интернета следећи корак је PMTiles извод Србије (Protomaps) послужен из `public/`.
Мапа има филтере (врста, епархија, век, одлике), „У близини“ (листа по удаљености од корисника) и ходочашће:
светиње се додају редом, рачуна се дужина пута, „Краћи редослед“ слаже обилазак (`src/lib/hodocasce.ts`), а навигација се
отвара у Google мапама са свим станицама. Ходочашће се чува на уређају.

Почетни скуп светиња је у `src/data/svetinje.json` (епархије у `src/data/eparhije.json`); координате треба проверити, а пуну базу допунити
из података епархија СПЦ и OpenStreetMap-а.

## Шта мора да прегледа свештеник или богослов

- пост: за 2026. степен поста по дану је преузет из црквеног календара (crkvenikalendar.rs) у `src/data/post/2026.json`;
  за друге године рачуна се по правилима (`postPoPravilima` у `src/lib/kalendar.ts`), која се за 2026. поклапају са календаром дан по дан.
  За нову годину додаје се `src/data/post/<година>.json` и упише у `KALENDARI_POSTA`. Списак празника са олакшицом (`OLAKSICA_ULJE`) треба да провери свештеник;
- текстове молитава у `content/molitve/` (кратке молитве су унете, дуже чекају текст из провереног молитвеника) и редослед јутарњег и вечерњег правила (`pravila` у заглављу фајла);
- списак и датуме крсних слава у `src/data/slave.json` и опис обичаја у `src/components/KrsnaSlava.tsx`;

- `src/data/praznici.json` — листа и ознаке црвених слова;
- лекције у `content/lekcije/`, описи у `src/data/oci.json` и `src/data/svetinje.json`;
- `src/data/svetitelji.json` је само узорак — потребан је пун месецослов из провереног извора.
